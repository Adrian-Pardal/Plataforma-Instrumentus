# Registro de sessões

Um arquivo por sessão de trabalho: `AAAA-MM-DD.md` (se o dia já tem um, `AAAA-MM-DD-2.md`). Gerado pela skill `/handoff`.
Cada um traz: data, duração, tokens (M10), e uma lista das intervenções do operador
classificadas pela taxonomia do [protocolo](../protocolo.md) (M1).
Não guarde segredos nem trechos de conversa; só contagens e uma linha por intervenção.
