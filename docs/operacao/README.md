# Operação

**Esta pasta responde:** o que fazer quando algo quebra?

| Pasta | Do que trata | Status |
|---|---|---|
| runbooks/ | o que fazer em cada problema conhecido | a criar |
| incidentes/ | relato de cada incidente | a criar |

**Diferença para o `help/`:** o [help](../help/README.md) é rotina (nada quebrou); aqui é problema (algo quebrou e é
preciso diagnosticar e consertar).
