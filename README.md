# Instrumentus

Plataforma de pesquisas com vários métodos (o primeiro é o de Aceitabilidade TFA; ver docs/adr/0004).
Documentação: [docs/README.md](docs/README.md).

*Research platform hosting multiple survey methods (the first one is the TFA acceptability method).
Documentation (in Portuguese): [docs/README.md](docs/README.md).*

## Base científica / Scientific basis

Cada método da plataforma segue uma regra de cálculo publicada e cita a fonte. A tabela dos métodos, com a
condição de uso de cada um, e uma ficha por método (como funciona, fundamentação, referências em ABNT com DOI) estão em
[docs/metodos/](docs/metodos/README.md).

*Each method follows a published scoring rule and cites its source. See [docs/metodos/](docs/metodos/README.md)
(in Portuguese).*

## Como citar / How to cite

Use os metadados do arquivo [CITATION.cff](CITATION.cff); o GitHub mostra o botão "Cite this repository".

*Use the metadata in [CITATION.cff](CITATION.cff).*
